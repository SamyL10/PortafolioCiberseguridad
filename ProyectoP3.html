SCENARIO

Escenario del Caso

Una operación internacional alertó a las autoridades de Nueva Zelanda sobre el ingreso de sustancias ilícitas. Dos pasajeros procedentes de Australia, John Fredricksen y Jane Esteban, fueron interceptados en el aeropuerto de Wellington con 1 kg de metanfetamina oculto en una maleta. Las autoridades identificaron dos posibles lugares de entrega: la biblioteca de Eastbourne y un inmueble en Petone, donde se aseguraron drogas, armas y la PC de escritorio de Steve Kowhai (Narcos-1).

SUMMARY

Resumen Ejecutivo

La evidencia Narcos-1 está íntegra (MD5 c63a3d19e9c9495b573f45be544e50f9). El equipo (SK-DESKTOP, Windows 10 Pro 1809) concentra su actividad relevante en el perfil Steve entre el 29 de enero y el 2 de febrero de 2019 (NZDT, UTC+13). Se halló la reserva de un vuelo Brisbane → Wellington para dos adultos, capturas de mapas hacia Petone y la biblioteca de Eastbourne, y ejecución de herramientas de cifrado (TrueCrypt) y esteganografía (Image Steganography).

Sección 3. Preparación y Verificación de la Evidencia

3.1 Conservación y Extracción del Archivo Original

Se descargó el paquete dividido Narcos1.zip (15 partes, de .001 a .015) y se extrajo mediante 7-Zip abriendo la primera parte para unir automáticamente los fragmentos. Las 15 partes originales se conservaron intactas sin modificaciones para mantener la cadena de custodia, trabajando exclusivamente sobre la copia extraída, la cual generó dos directorios: Image (imagen de disco) y Memory Dump (volcado de RAM).

3.2 Verificación de Integridad con FTK Imager

Primero se revisó Narcos-1.001.txt para obtener los hashes MD5 y SHA1 de referencia de la adquisición original (17-feb-2019, 21 segmentos). Luego se abrió FTK Imager 4.3.1.1 en modo de solo lectura, se seleccionó Add Evidence Item → Image File y se cargó el primer segmento (Narcos-1.001), verificando que la tabla de particiones GPT se leyera correctamente. Finalmente se ejecutó Verify Drive/Image sobre los 30 GB (62,914,560 sectores), confirmando Match en ambos algoritmos y cero bloques dañados.

3.3 Creación del Caso e Ingesta en Autopsy 4.23.1

Para interpretar artefactos de Windows (registro, navegadores, Prefetch) se creó el caso PR03_Narcos (Single-User) en un directorio separado de la evidencia, registrando los datos del examinador y la UPSLP. Se importó Narcos-1.001 como Disk Image or VM File configurando la zona horaria Pacific/Auckland (para mostrar fechas en NZDT) y activando únicamente los módulos de ingesta relevantes (Recent Activity, Hash Lookup, Picture Analyzer, Keyword Search, Encryption Detection y Data Source Integrity).

Sección 4. Parte I — Extracción e Identificación (P1 – P15)

P1. ¿Qué edición y versión de Windows se encuentran instaladas en el equipo?

Se consultó primero Data Artifacts → Operating System Information, lo que identificó el equipo SK-DESKTOP con Windows 10 Pro (AMD64) y propietario Steve. Para obtener la versión y compilación exactas, se buscó el hive SOFTWARE (68 MB en Windows\System32\config) y se abrió la clave Microsoft\Windows NT\CurrentVersion, confirmando Windows 10 Pro, versión 1809, compilación 17763.107 (InstallDate: 29/01/2019 08:15:39 NZDT).

P2. Nombre de la carpeta del perfil principal y ruta absoluta

Navegando por Data Sources → vol7 → Users se compararon las cinco carpetas existentes (All Users, Default, Default User, Public y Steve). Solo Steve (C:\Users\Steve) contiene documentos, descargas, AppData con programas instalados y el hive NTUSER.DAT activo modificado hasta el 2019-02-02 15:39:26 NZDT.

P3. Ruta de la clave UserAssist que registra actividad de programas

Abriendo C:\Users\Steve\NTUSER.DAT en el visor de registro (pestaña Application), se navegó hasta HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\UserAssist. En la subclave {CEBFF5CD-ACE2-4F4F-9178-9926F41749EA}\Count se encontraron 43 valores codificados en ROT13 que registran los ejecutables abiertos por el usuario.

P4. Navegadores con actividad y sus bases de datos de historial

En Data Artifacts → Web History (994 registros), al ordenar por Program Name se identificaron dos navegadores activos: Microsoft Edge (Legacy), cuya base de datos ESE es C:\Users\Steve\AppData\Local\Microsoft\Windows\WebCache\WebCacheV01.dat, y Google Chrome, cuya base SQLite es C:\Users\Steve\AppData\Local\Google\Chrome\User Data\Default\History.

P5. Hash MD5 del archivo History del perfil Default de Chrome

Seleccionando un registro de Google Chrome en Web Downloads y abriendo la pestaña Source File Metadata, se confirmó la ruta Chrome\User Data\Default\History (360,448 bytes, última modificación 2019-02-02 15:28:48 NZDT) y su hash MD5: f3f979c6dee9fbb7cbdf5818aaa4b723.

P6 y P7. Ruta absoluta y fecha de creación de airport crystals.jpg

Mediante Tools → File Search by Attributes (Name: "airport crystals") se localizó el archivo junto a su flujo Zone.Identifier y accesos directos .lnk. En File Metadata se confirmó su ruta absoluta C:\Users\Steve\Documents\Misc\airport crystals.jpg y su fecha de creación exacta: 2019-01-31 10:25:18 NZDT (77,643 bytes).

P8 y P9. Hash MD5 y fecha de última modificación de dropoff.jpg

Con File Search by Attributes (Name: "dropoff") se ubicó C:\Users\Steve\Documents\Misc\dropoff.jpg (177,888 bytes). Su pestaña File Metadata registró el hash MD5 7feb763bebe42c3a3464c9ee3bb1d3e8 y la fecha de última modificación 2019-02-02 14:06:06 NZDT (un segundo después de crearse, comportamiento típico de una captura guardada).

P10. Imagen relacionada con reservaciones de vuelo en Documents\Misc

Al no conocerse el nombre exacto, se buscó la palabra clave "flight" en File Search by Attributes (34 resultados), identificando el único archivo de imagen en la carpeta objetivo: flightbookings.PNG en C:\Users\Steve\Documents\Misc\flightbookings.PNG (52,971 bytes, creado el 2019-02-02 15:28:44 NZDT).

P11. Hash MD5 del archivo Method run.jpg

Buscando "Method run" se localizó C:\Users\Steve\Documents\Misc\Method run.jpg (145,213 bytes). Su MD5 es 69b225bc0ef5a0c003f1e2a6646aaf92. Entre su creación (10:21:24) y modificación (10:22:24) hubo un minuto exacto, compatible con las anotaciones a mano agregadas a la imagen.

P12. Hash MD5 completo de BNE.png

Localizado en C:\Users\Steve\Downloads\Misc\BNE.png (4,376,793 bytes), presenta el hash MD5 dffa98bdd7371d1806adb09db27ba283. Su flujo Zone.Identifier y Web Downloads confirman que Chrome lo descargó desde mail.protonmail.com el 2019-02-01 a las 13:13:19 NZDT.

P13. Instalador de herramienta de esteganografía en Downloads

Revisando Data Artifacts → Web Downloads (34 registros) se detectó la descarga desde SourceForge de Image Steganography 1.5.2 Setup.exe el 2019-02-01 a las 13:16:32 NZDT, guardado en C:\Users\Steve\Downloads\Image Steganography 1.5.2 Setup.exe (559,616 bytes) con hash MD5 c9b7c382dea6d7f45ae1bf437860cb69.

P14. Instalador de herramienta de cifrado encontrado en Downloads

A partir de Web Downloads y confirmando con File Search by Attributes ("TrueCrypt"), se identificó el instalador TrueCrypt Setup 7.1a.exe en C:\Users\Steve\Downloads\TrueCrypt Setup 7.1a.exe (3,466,248 bytes, creado el 2019-01-30 12:27:43 NZDT, MD5 7a23ac83a0856c352025a6f7c9cc1526).

P15. Rutas de la caché de Discord y de ActivitiesCache.db (Windows Timeline)

Se localizó la base de datos SQLite de Windows Timeline en C:\Users\Steve\AppData\Local\ConnectedDevicesPlatform\2418c0082017486a\ActivitiesCache.db (2 MB, modificada hasta el 2019-02-02 15:36:38) junto a sus archivos -shm y -wal. En el árbol de Roaming se ubicó C:\Users\Steve\AppData\Roaming\Discord\Cache con 130 elementos activos durante todo el periodo del caso.

Sección 5. Parte II — Investigación, Interpretación y Análisis (P16 – P20)

P16. Coincidencias entre flightbookings.PNG, BNE.png, dropoff.jpg y airport crystals.jpg

Al inspeccionar el contenido visual en la pestaña Application, las imágenes trazan una logística coherente: flightbookings.PNG muestra una reserva para 2 adultos Brisbane (BNE) → Wellington (WLG) el 16-feb-2019 (descargada desde Discord); BNE.png es una fotografía de Brisbane recibida por ProtonMail; dropoff.jpg marca Eastbourne Library (uno de los puntos de entrega señalados); y airport crystals.jpg traza la ruta en auto desde el aeropuerto de Wellington hasta Eastbourne pasando por Petone. No se confirman nombres de viajeros ni remitentes.

P17 y P18. Origen local de los mapas (ScreenSketch) y evidencia de Discord

Method run.jpg muestra un circuito con varias paradas desde Eastbourne anotado a mano como "Home". Al revisar el flujo alterno Zone.Identifier de airport crystals.jpg y dropoff.jpg se encontró LastWriterPackageFamilyName=Microsoft.ScreenSketch (app Recortes y anotación). Esto se correlaciona con Recent Documents (tres aperturas de ms-screensketch segundos antes de crear cada mapa) y UserAssist, demostrando que las capturas se hicieron en este equipo. Respecto a Discord, su instalación, caché, enlaces en Recent Documents y la descarga de flightbookings.PNG prueban su uso con la cuenta Steve, pero sin recuperar los mensajes no pueden concluirse conversaciones ni interlocutores.

P19 (Parte A). TrueCrypt 7.1a: Descarga, Instalación, Ejecución y "secret"

Los archivos Prefetch y Run Programs demuestran que el 2019-01-30 se ejecutaron el instalador (12:28:17), TrueCrypt.exe (12:31:25, Count = 1) y el asistente TrueCrypt Format.exe (12:31:29, Count = 1). Cuatro minutos después se creó Recent\secret.lnk apuntando a Documents\secret, archivo que hoy figura eliminado (Unallocated, tamaño 0). En Encryption Suspected solo aparecieron bases de datos del sistema (falsos positivos), por lo que no hay un contenedor cifrado recuperable.

P19 (Parte B). Image Steganography 1.5.2

Prefetch y Run Programs confirman que el 2019-02-01 se ejecutó el instalador a las 13:16:46 y el programa Image Steganography.exe diez segundos después (13:16:56, Count = 1), apenas 3 minutos después de recibir BNE.png por ProtonMail. Aunque se demostró su ejecución, el uso efectivo sobre BNE.png o package.jpg no está probado sin extraer un mensaje oculto.

P20. Hipótesis, Explicación Alternativa y Evidencias Adicionales

Hipótesis: El equipo SK-DESKTOP (perfil Steve) se empleó para coordinar la logística del ingreso y reparto de metanfetamina (reserva Brisbane–Wellington para 2 adultos, rutas hacia Petone y la biblioteca de Eastbourne, circuito desde "Home") y para ocultar información con TrueCrypt e Image Steganography, además de ejecutar CCleaner.

Explicación alternativa: Un viaje legítimo de familiares o amigos desde Brisbane, rutas personales y pruebas de software de privacidad por curiosidad, ya que ninguna imagen contiene referencias explícitas a narcóticos.

Evidencias adicionales necesarias: Recuperar las conversaciones de Discord (Local Storage/leveldb) y correos de ProtonMail, aplicar estegoanálisis a BNE.png y package.jpg, realizar carving del espacio no asignado para recuperar Documents\secret y analizar el volcado de RAM (Narcos-Mem-1) en busca de claves de TrueCrypt.
